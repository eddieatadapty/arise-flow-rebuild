# Arise Growth Audit

**Live → https://eddieatadapty.github.io/arise-flow-rebuild/**

Five ideas to turn more Arise users into subscribers, each built into a clickable version of Arise's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Snap a meal before the price | +10–20% CR to purchase |
| 02 | Say what they told you on the paywall | +10–15% CR to purchase |
| 03 | Ask for reminders and Health after the plan | +10–15% CR to purchase |
| 04 | Put a result next to the button | +5–10% CR to purchase |
| 05 | One clear year, a smaller plan on close | +5–15% CR · ARPU +10–15% |

Every price, rating and feature comes from Arise's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Arise. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
